# Mitarbeit

Das Projekt lebt von nachvollziehbaren Änderungen, solidarischem Feedback und der radikalen Vorstellung, dass auch eine Datei einen sinnvollen Namen verdient.

## Arbeitsweise

1. Für Änderungen einen kurzen Zweig anlegen, beispielsweise `text/szene-4-klarheit` oder `grafik/neue-karte`.
2. Kleine, thematisch zusammenhängende Commits schreiben.
3. Einen Pull Request mit Zweck, betroffenen Szenen und durchgeführten Prüfungen eröffnen.
4. Binärdateien nicht unnötig neu speichern; selbst eine unsichtbare Word-Änderung kann sonst 65 MB politische Debatte erzeugen.

## Prüfliste für Textänderungen

- Zeitlogik bleibt widerspruchsfrei.
- Hinweise besitzen mindestens einen alternativen Fundweg.
- Entscheidungen werden nicht durch eine einzelne Probe blockiert.
- Sprache ist genderneutral oder nutzt den Genderstern.
- Humor richtet sich nach oben, gegen Systeme oder ins Absurde, nicht gegen marginalisierte Personen.
- Änderungen erhalten die humanistische, solidarische und herrschaftskritische Perspektive des Abenteuers.

## Prüfliste für Regeln

- Daggerheart-Begriffe werden konsistent verwendet.
- Gegner*innen bleiben für vier Figuren auf Stufe 1 handhabbar.
- Fear erzeugt Konsequenzen und Bewegung statt bloßer Schadenssteigerung.
- Kämpfe besitzen Motive, Rückzugsmöglichkeiten oder alternative Ziele.
- Die Zwei-Abende-Fassung bleibt innerhalb des Zeitbudgets.

## Prüfliste für Grafiken

- Spieler*innenmaterial enthält keine geheimen Orte oder Enden.
- Beschriftungen sind lesbar und korrekt geschrieben.
- Karten bewahren die etablierte Topologie.
- Neue Bilder passen zur warmen solarpunkigen Clockpunk-Bildsprache Veyras.
- Druckmaterial wird mindestens einmal als PDF gerendert und visuell geprüft.

## Große Dateien

PDF, DOCX, PNG und JPG werden durch Git LFS verwaltet. Generierte ZIP-Pakete und Renderverzeichnisse gehören in GitHub Releases beziehungsweise bleiben lokal.
